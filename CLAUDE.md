# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Altype ("Your language. Your shortcut."; called 2Talker until 0.3, tu-talk before that): a Windows tray app (Electron) that translates a picked text offline and reads the English aloud; it also translates any text both ways like DeepL, reads text from the screen, and switches and fixes keyboard layouts (in place of EveryLang). A sibling of the Language Tutor in `ikstro/cc-translator` (`E:\Cursor\Plugin\CC-translator`): the card's webview, the natural voice, the system voice and the word dictionary were copied from its `panel/` and adapted; the two repositories do not share code at build time.

## Commands

```
npm install
npm test                          # vitest
npx vitest run src/translate.test.ts
npm run typecheck
npm run build                     # esbuild: dist/main.js, preload.js, mt-worker.js, voice-worker.js, kbd-worker.js, field-worker.js; media/card.js, app.js, tray.js; codicons into media/
npm start                         # build + electron .
npm run dist                      # electron-builder → release/2Talker-Setup-<version>.exe (NSIS, win-x64)
npm run icons                     # the "alt" keycap mark (build/icon.svg's shapes, drawn on a canvas under Electron) → build/icon.png (512), build/icon.ico (16–256), media/icon.png (128), media/tray.png + tray@2x.png (16 set pixel by pixel, 32)
npm run models                    # scripts/build-mt.mjs: src/mt-manifest.json + vendor/bergamot from Mozilla
npm run glyphs                    # scripts/build-glyphs.mjs: the Lucide icons the pages use (lucide-static, MIT) → src/webview/lucide.ts
npm run shots                     # scripts/shots.mjs: every page, the tray panel and the badge pictured offscreen → .cache/shots/*.png (build first; runs beside the installed Altype)
node scripts/build-words.mjs      # media/layout/{en,ru,uk,bg,mk,el,he,ar,fa,ka}.txt: the layout fixer's word lists (FrequencyWords; it has no be, kk, hy, and its sr is Latin)
cd engine; uv sync --extra speakers-gpu --group dev   # the speech engine for development, in engine/.venv
npm run test:engine               # engine/tests in engine/.venv (uv run --no-sync); the release workflow runs it on the core part
```

One Altype at a time, always: `main.ts` takes the single-instance lock on Altype's own folder before anything else, so a second start (installed, `npm start` or a test run) hands its arguments to the first and quits. A test run (`ALTYPE_TEST_HOME=<folder>`: its own settings and speech engine folder, `ALTYPE_TEST_PORT`, 8797 by default, Windows' startup list left alone) therefore needs the installed Altype quit first.

Uninstall (`build/installer.nsh`, `customUnInstall`) asks once whether the data goes too: Yes removes `%APPDATA%\Altype` (and `2Talker`, `tu-talk`), `%LOCALAPPDATA%\Altype` (the speech engine) and `Documents\Altype` (transcripts); No keeps everything for a later install; an update (`--updated`) and a silent uninstall never ask or delete; notes in the knowledge base are never touched.

Release: bump `version` in package.json, commit, tag `v<version>`, push the tag. `.github/workflows/release.yml` builds the installer on windows-latest and publishes the GitHub release with `latest.yml`; installed copies update from it (`src/update.ts`, electron-updater, checked at start and every 6 h, installed on quit). The installer is unsigned.

A shell started from VS Code or Claude Code may carry `ELECTRON_RUN_AS_NODE=1`; Electron then runs as plain Node and `electron.app` is undefined. Run with it unset (`env -u ELECTRON_RUN_AS_NODE …`).

## Architecture

Main process (`src/main.ts`): tray, the card window, the app window, flows. `%APPDATA%\2Talker\`: `settings.json` (`settings.ts`), `models\<code>\` (translator), `voice\` (Kokoro), `dict\`; `words.json` (`words.ts` `WordStore`: the notebook, one entry per dictionary form; `ankiTsv` for Anki's import); `adoptOldFolder` moves them over from `%APPDATA%\tu-talk` once. Closing the card (`hideCard`: Esc, ✕, a click elsewhere) also sends `stop` to the card, which plays the natural voice's audio itself.

- **Selected text**: `winclip.ts` registers the card window as a clipboard listener (user32 through koffi; `WM_CLIPBOARDUPDATE` via `hookWindowMessage`). `clipboard.ts` `DoubleCopy`: two changes 40–650 ms apart with Ctrl held = a request (`doubleCopy` setting); changes closer than 40 ms are one copy announced in several formats. Copies made inside the focused card are ignored. The selection shortcut (`selectKey`, none by default) waits until its keys are let go, presses Ctrl+C in the program in front (`pressCopy`, `keybd_event`) and takes the next clipboard change within 600 ms (`copyWanted`). `registerShortcuts()` registers it and `snipKey`; either may be empty.
- **Screenshot**: the snip shortcut (`snipKey`, default Ctrl+Alt+S) opens `ms-screenclip:` (Windows' snipping overlay); the next picture on the clipboard within two minutes is the snip (`clipboard.read()`, `image/png`; Electron 45's clipboard API is async). `ocr.ts` runs `Windows.Media.Ocr` through Windows PowerShell (`-EncodedCommand`, never `-ExecutionPolicy`), the person's language engine first (it reads Latin too), then English; `ocrtext.ts` joins lines into paragraphs by their boxes. Two purposes (`Purpose`), each from the selection or the screen: **listen** (the card above: `doubleCopy`, `selectKey`, `snipKey`) and **translate**, the translator (`translateKey` with `useSelection('translate')`, `textKey` with `snip('translate')` → `readScreenText`): the same card in kind `translate` or `text`, the text as it is (editable), Copy, From ⇄ To over the 32 languages, translated at once (`translateWindow`, `translateTextCard`). `translate.ts` `languageOf` guesses the source (a script of one language; letters of one language: қ… kk, і/ї/є/ґ uk, ђ… sr, ы/э/ё ru, پ… fa; else the language with most of its 200 common words in the text, `media/lang-words.json`; a short text: English by `media/layout/en.txt`), the vote and the English rule only among the languages the person uses (`pool`: `settings.ts myLanguages`: their own, English and `languages`, chosen in Settings; a script none of them uses falls back to all 32), `targetFor` the target (the person's own, English from it), `translatePlain` translates through English when neither side is. No Translate button: an edit is translated again after a 700 ms pause (the last translation shown faded meanwhile), a language picked at once. Swap (framed, after the languages) swaps them and, a translation in, makes it the text (DeepL's way). Paste (blue; Enter on the window or in the field, Shift+Enter a new line; a translation still coming is pasted once in; only for a selection, `canPaste`): `pasteTranslation` brings back the window the text was selected in (`focusWindow`, `SetForegroundWindow` while the card is in front), hides the card and pastes over the selection through the clipboard. The selection keys (`useSelection`) and Paste put the clipboard back as it was (`saveClipboard`, `restoreClipboard`); Ctrl+C twice is the person's own copy.
- **Translation**: `translate.ts` `pairText` splits lines into sentences (`sentences.ts`) and decides each sentence's direction by script (`directionOf`): the person's script → into English (English shown, original behind the tap), Latin → into their language. Same-script natives (German…) are treated as English source for now. `splitText` + `translateLines`: when no sentence goes into English (`englishReady`), `main.ts` `translateInto` shows the English at once (`done` with the translation `translating`/`downloading`) and the card starts reading while the translation comes. `render.ts` writes two halves as plain paragraphs, one per line (no markdown: a picked text is not markdown; `sentences.ts` `unwrapLines` first joins lines broken mid-sentence: a line ending in a letter, digit, comma or hyphen followed by one starting in lower case without a list marker; a list item goes on so too): `englishHtml` (`span.s[data-i]`) and `translationHtml` (`span.t[data-i]`).
- **Translator** (`engine.ts`, interface `translator.ts`): Firefox Translations (Bergamot, WebAssembly, `vendor/bergamot`, shipped). Models per pair from Mozilla's attachment CDN, pinned with size and SHA-256 in `src/mt-manifest.json`, stored as `<sha256 head>-<name>`. `scripts/build-mt.mjs` picks, per direction, the newest complete version whose filter expression passes for Windows release (en→ru 2.0; the nightly 2.1 invents words). The engine runs in a worker thread (`mt-worker.ts`, loader via `vm.compileFunction`, Firefox's decoder config), ended after 5 idle minutes.
- **App window** (`media/app.html`, `src/webview/app.ts` with `ui.ts` (cards, keys), `speech.ts` (the engine's offers, models, the key) and `transcripts.ts` (Transcribe and Transcripts), `media/app.css`; the design is `design-lab/2026-10-27-altype/comps/01-chain/` for the chain line and the moment, and `design-lab/2026-10-28-standard/` for the look since 0.8 (the owner's approved prototype), both kept out of git): no Windows frame (`frame: false`); its header is the window's bar on every view (drag region: the "alt" keycap turned over (`.key.mark`) + "altype", pills Home · Words · Transcripts · About, Settings, then minimize, maximize and close drawn like the card's buttons, `{type: 'window'}`; main answers `appWindow {maximized}` on the window's own events, so the glyph follows a double click on the bar or Win+↑ too; close hides). **The look is the standard one** (2026-10-28): every line of a page is a card (`ui.ts` `row`, `card` with a Lucide icon, `navCard` with a value and a chevron, `toggleCard`; `.row` in app.css: `--surface`, 1 px `--border`, 6 px corners, 4 px apart), groups are sentence-case headings (`grp(text, count?, link?)`), icons are Lucide (`src/webview/lucide.ts`, generated by `npm run glyphs` from the names in `scripts/build-glyphs.mjs`; `lucide(name)`, 20 px on a card, `.s` 16 px; codicons stay only in the card and the transcript view), and the content keeps to one column of 800 px however wide the window is (`--side` on `.home`, `.pg`, `.stage`). **A card with a chevron opens a second-level page** (`SubId`, `SUBS` in app.ts: `openSub`/`popSub`, `slideBody` moves the old body out as a ghost and the new one in, 220 ms; the title becomes a crumb "Transcribe › Words to spell" (`.pcrumb` goes back), the keys hide, Back and Esc return to where the page was scrolled; `open.sub` is dropped by `openPage`, `closePage` and a `valid` check): Words to spell, Recent phrases, Speech model (of the open action), Google Meet, Who spoke when (where it runs, the graphics card or the processor, each with its download and an hour's time; its download or switch; then the Hugging Face key, unless the voices' model is on the disk already), Layouts, Programs left out, Kept as typed, Languages you use, Speech engine, This computer. **A list is a page**: an add card on top (`listPage`: a field and Add, Enter adds, Escape clears; Words to spell has two fields, the word and what it is heard as, and a tap on a word puts it back into them), then one card per item with a cross; the fields are `liveField`s (`data-live`), which `renderBody` carries over into the new body (`carryFields`) so what is typed survives a redraw and an added item shows at once. Over **Home**, always the first view: the chain line "ghbdtn vbh → привет мир → hello world" with Replay, a readiness line (`AppView.translator` for the person's pair, the natural voice, "runs on this computer"), and six action rows with the person's real keys (Listen, Translate, Screen, Dictate, Transcribe, Keyboard). The opening moment (5.7 s: the line is fixed, translated and read, each step's key lit, then it travels into the header and the keys drop into their rows) plays while `settings.introSeen` is false, which the page then sets; Replay plays it again. **A tapped row or pill grows into a full-window page** (its title and keys stay put as the page header, the other rows slide down and fade; Back and Esc fold it back; springs, no sheets): Listen, Translate, Screen (their keys, recorded from a press by `hotkey.ts` `HotkeyRecorder` — a tap waits `DOUBLE_MS` for a second one — clearable with ×, never two equal, "taken" from `keysOk`; card options; a text to try), Dictate (its keys, the knowledge base folder and its notes subfolder, Words to spell (`vocabulary`: a name, or a word with the ways it is heard in parentheses; `vocabulary.ts parseEntry`; sent to the engine with the plan), the dictation model; the engine's download offer while it is missing), Transcribe (a drop zone, also anywhere in the window, a file picker, language and speaker count, a microphone recording; the speakers part and the Hugging Face key with its live states and four steps; the Chrome extension's steps; the time an hour takes here, `minutesPerHour`), Transcripts (the library, searched by the words, and a transcript: in-place progress with stages, position and time left; speakers to rename and change; editable lines; the sound under it, a click on a time plays from there; export, copy, to the knowledge base, split by speaker or transcribe again, delete), Keyboard (switch and fix keys, the layouts in order, fixing as one types, programs left out, words kept, the badge, the rivals warning, the privacy line), Settings (language, the languages the person uses (`languages`, their own and English always in: dictation's `expected` with `strict`, the Translate card's and the English key's guess, the screen's text in that order, the fixer's default cycle), voice and the natural voice download, speed, theme, start with Windows, the speech engine's parts, graphics card, service, folders and Remove, version and updates), Words (search, remove, Export for Anki, Copy), About (mark, tagline, author, links through `openLink` and the `LINKS` allowlist, credits). Fed by one `ToView {app, AppView}` snapshot, re-sent by `postApp()` on any change, and `appTab` (`AppTab`: home, the action pages, words, settings, about; the tray's "About Altype…" opens About); opened from the tray's panel, on the first run (Home), and by a second start without a command. Closing hides it.
- **Tray panel** (`media/tray.html`, `src/webview/tray.ts`, `media/tray.css`): Windows' tray menu cannot take Altype's look, so either click on the tray icon opens a frameless window of Altype's own by the icon (`createTrayPanel`, made at start and hidden between uses; `placeByTray` in `placement.ts`: on the side away from the taskbar, inside the work area; as tall as its content, `trayHeight`); it hides on blur, and a click on the icon that took its focus only closes it (`TRAY_REOPEN_MS`). Fed by `TrayView` (`refreshTray`), 340 px wide (`TRAY_WIDTH`), the look of `design-lab/2026-10-28-standard/tray.html`: the brand and Open at the top (both open the window) with the state (ready · downloading… · paused in amber), then the commands as full phrases with a Lucide icon and their keys quiet on the right: Listen to the copied text (Ctrl+C twice), Translate the copied text, Listen to a screen snip, Translate a screen snip, New note / Save the note and Transcripts once the engine is installed; **Quick settings**: Fix the layout as I type (`autoFix`), Ctrl+C twice listens (`doubleCopy`), Pause Altype (`paused`), each a switch saved at once (`saveSettings`, the panel stays); Settings and Quit as the last rows. A command (`TrayCommand`) hides it and runs as the keys do; the commands work while paused. The voice, speed, language, theme and the rest live in the window only; "the selection" is not offered (from the tray it is gone).
- **Voice**: `synth.ts` + `voice-worker.ts` + `kokoro.ts` + `voicestore.ts` (natural voice, files from cc-translator's `voice-1` release), `speech.ts` (System.Speech), unchanged from the panel apart from paths and the `phonemes` message: the voice process's eSpeak gives a word's IPA for the word card (`lookup` → `ipa`), only while the natural voice is downloaded. `NaturalSpeaker` keeps the last 60 made sentences by text, voice and speed and mirrors the process's queue (`requests`): a new reading takes cached audio at once and waits for a sentence still being made for a stopped one instead of asking twice; the card asks for the sentence after each reading ahead (`speakNatural.ahead`), so ⏭ and the next paragraph start at once. `autoplay-policy=no-user-gesture-required` so the card can read before it is touched. **Fitting each computer** (2026-10-28, measured on the i9, a sentence's making over its playing): the shipped uint8 model is the right one on a processor (0.25 with 4 threads, 0.55 with one); int8 "quantized" is 3.4× slower (0.85) and fp16 no quicker (0.27); DirectML on an RTX 2080 SUPER only 1.5× (0.165, uint8 or fp16 alike), so no other model and no card are shipped (`voice-worker.ts` takes `TUTOR_MODEL` and `TUTOR_EP=dml` for trying them; DirectML needs `DirectML.dll` beside the runtime, which the voice's download does not have). The voice gets the physical cores as threads once `device.ts` knows them (`SpeakerOptions.threads`), and measures itself while it reads (`took` per sentence, `nextVoiceSpeed`, kept in `device.json` `voice`, dropped with another computer's profile): Settings say how much faster than it plays it makes speech, and when it is slower than it plays (it pauses between sentences), say so and offer a Windows voice (`NaturalState.rtf`).

Card (`media/card.html`, `src/webview/card.ts`): the panel's `player.ts`, `hover.ts`, `dom.ts`, `voices.ts`; `preload.ts` exposes `window.tutorHost.post` and forwards `to-view` IPC as window messages. States: reading, translating, downloading, done (English + `TranslationState` of the lower half), empty, no-ocr, failed (`protocol.ts`). English on top (`.body`, read by Listen), translation under it (`.translation`, outside `.body` so the word card skips it); a click on an English word opens the word card (`hover.ts` `showAt`), a click on a sentence marks its pair (`.pair`); the language button hides the lower half; Esc closes. The remote under the English: ⏮ Listen ⏭ and the "One by one" chip (`oneAtATime`): Listen reads from a cursor (the sentence being read, via `PlayerEnv.entered`) to the end, or one sentence and waits; a finished full reading puts the cursor back at the top; Space and ← → work too. With two paragraphs or more, each gets a ▶ in a 26 px left margin (`addParagraphButtons`, shown on hover), reading that paragraph. The word card (`hover.ts`), opened by a click, takes clicks itself: say the word (`player.play` on a detached span), a star that saves it (`saveWord` with the sentence around it) or removes it. `rare.ts` draws a CSS Highlight `rare-word` (dotted underline) under words none of whose `baseForms` are in `media/common-en.txt` (3000 words, OpenSubtitles frequency, CC BY-SA; sent once as `common`); names mid-sentence are skipped; `rareWords` setting. The window follows the body's height (`height` message → `fitCard`), up to `cardHeight` or 70 % of the work area; it is resizable: a drag of an edge (`will-resize` … `resized`, never the card's own growing) saves `cardWidth` and/or `cardHeight`. A Maximize button in the header (between pin and close; a double click on the bar too, `WM_NCLBUTTONDBLCLK`) fills the work area of its screen (`maximizeCard`: pinned and not resizable meanwhile, `fitCard` idle, the field grows with its text); Restore brings back the size and the pin state from before; a hidden card forgets it. Opens by the pointer (`placement.ts`), hides on blur unless pinned. The header draws the key that called the card (`CardView.via`, hotkey.ts notation, "Control+C*2" for Ctrl+C twice; main passes it from the key's handler, none from the tray) as lit keycaps, then the function's name (Listen, Listen · screen, Translate, Translate · screen).

Look: `media/theme.css` holds Altype's materials for every page — since 2026-10-28 the neutral colors of standard settings (Windows 11's grays: light `--bg` #f3f3f3 / `--surface` #fbfbfb, dark #202020 / #2b2b2b; `--raised`, `--overlay`, `--selected`, `--border`; `--text`, `--strong`, `--muted`; a plain blue `--accent` #0067c0 / #4cc2ff with `--accent-hover` and `--on-accent`; `--green`, `--red`, `--orange`) chosen by `prefers-color-scheme` (which `nativeTheme.themeSource` sets from the `theme` setting: system, light, dark; `nativeTheme.on('updated')` repaints the windows when Windows switches), Inter for all text and JetBrains Mono only for keys, times and numbers (bundled in `media/fonts`, OFL), 6 px corners on cards and controls (`--r-sm`; the pill shape is left to toggles, chips and toasts), the type scale, the `.key` keycap (`.key.lit` for a key at work, `.key.mark` the brand's inverted one) and `svg.lu` for the Lucide icons; the old `--vscode-*` names still point at the same colors. `main.ts` paints a window's background before its page (`cardColor`, `appColor`) and, on Windows 11, **one frame** instead of two: `src/dwm.ts` `frameWindow` sets DWM's border to the theme's `--border` (`borderColor`) and the corner preference (round for the card, the tray panel and the badge; the window's default) through koffi's `dwmapi`, the pages load with `?frame=dwm` and make their own 1 px border transparent (`html.dwm`, `dwmFlag()` in dom.ts), so the sizes stay; Windows 10 keeps the CSS border. The layout badge (`media/badge.css`) is an inverted keycap pill.

- **Pause** (`paused`, Settings and the tray's Quick settings, kept between starts): `registerShortcuts` registers nothing (every key marked ok), `applyKeyboard` gives the helper empty keys so its thread stops, Ctrl+C twice is ignored, a recording is cancelled, the tray icon dims (`media/tray-paused.png`, drawn by `npm run icons` at 0.45 alpha) and the tooltip says paused; Home shows a notice with Resume; the tray panel's commands still work by a click.
- **Keyboard helper** (off until a part is on: `switchKey`, `fixKey`, `autoFix`, `layoutBadge`): `keyboard.ts` `KeyboardHelper` runs `kbd-worker.ts`, a thread with Windows' low-level keyboard and mouse hooks (koffi `register`) and its own `GetMessageW` loop; the main process posts on a `MessageChannel` port and wakes it with `PostThreadMessageW` (`WM_APP`), the thread pulls with `receiveMessageOnPort`. All decisions are `typist.ts` `Typist` (unit-tested with a simulated text field, `typist.test.ts`): the keys typed since the last click as strokes (vk, Shift, Caps, layout id), never their letters; `hotkey.ts`: every key of the app, written like Electron's accelerators plus what only the hook can catch: a modifier tapped alone "LeftControl" or twice "LeftControl*2", a chord "Control+Shift", "Pause" alone, the mouse's side buttons "MouseBack", "Control+MouseForward". `isAccelerator` decides: the select, snip and text keys go to `globalShortcut` when Electron can hold them, to the keyboard thread otherwise (it reports `hotkey`, main runs the action); the layout keys are always the thread's. A tap acts at once; a double of the same key within `DOUBLE_MS` takes back the first tap's layout switch and acts. The switch key posts `WM_INPUTLANGCHANGEREQUEST` to the window in front with the next layout of `layouts` (when empty: the installed layouts of the languages the person uses, all of Windows' if that leaves fewer than two). At a word's end `layoutfix.ts` `chooseFix` (word lists `media/layout/*.txt`, trigram plausibility) may retype it: the hook swallows the ending key, `typeFix` runs after the hook answers (`WM_APP+1`): layout first, then Backspaces and the text (`winkbd.ts` `press`, `SendInput` marked `OWN_KEYS`), keys typed meanwhile pressed again. Backspace (or the fix key) right after takes it back and adds the word to `keepWords`. The fix key: the last word only, into the layout that makes the best word of it (`bestLayout`), again round the cycle; an explicit press converts a word with digits or a kept word too; after a selection (drag, double click, Shift+move, Ctrl+A) the main process converts it (`convertSelection`: copy, `convertText`, paste, clipboard restored, `ownClipboardUntil`). The badge: a 150 ms look at the layout in front, a click-through window (`media/badge.html`) by the system caret (`GetGUIThreadInfo`) or the pointer. `fixApps` leaves programs out; the settings warn when EveryLang or Punto Switcher runs (`findRivals`, `RIVALS`) and name, calmly, other programs that watch the keyboard (`KEYBOARD_APPS`: AutoHotkey, WhisperTyping…) and whether one presses keys by itself (`foreignKeys`: the thread reports the first injected key that is not Altype's, its main process's Ctrl+C/V marked `MAIN_KEYS`, or a mask key). Such keys never make or break a tap (a 2026-10-27 trace: a program pressed Right Ctrl+key 0.4 s after the owner's Shift+letter, which broke double taps before they were ignored).

- **Keyboard helper since 2026-10-29** (over the paragraph above where they differ): `fixApps` became `apps` (`AppRule {exe, off: fix|switch|badge|keys, layout}`, `normalize` moves an old `fixApps` over; a program's page under Keyboard › Programs, "Add a running program" from `windowedApps`); a layout's own key (`layoutKeys`, `KeyAction 'layout'`, recorded on the Layouts page); `switchOn`/`fixKeyOn` turn keys off without losing them. `typist.ts`: at a word's end the short words before it (1–3 letters, same layout) go with a fixed word when they were meant there (`layoutfix.ts meantThere`: none as typed, or ×10 rarer than there, `RARE` by length; "в Telegram", "it." stay); `chooseFix` fixes a word known as typed only when its sign keys are letters of a much commoner word (";t" → "же") or it is learned (`always`); `caseSlip` sets right two capitals (`fixTwoCaps`) and Caps Lock left on with Shift on the first letter (`fixCapsLock`, Caps goes off), both only when the word set right is in a word list in some layout (`listed`, never a learned word: sRGB or iOS typed with Caps Lock on stay, Caps too); Backspace right after restores the keys as typed and Caps Lock (`autoFixed.typed`, `toggleCaps`); a capital inside ("ыКПИ") is fixed only into a word the person taught (`chooseFix` `mine`, `mineKey`); `keepCaps`; the person's switch (their key, a layout key, or Windows' own seen as a layout change not Altype's, `ownSwitch`) sets `boundary` (the fix key never reaches back over it) and `trustNext` (the next word is not fixed); the fix key takes the tail (`wordsMeant` with no length cap); `fixOnPause` (`tick` every 150 ms, `PAUSE_MS`, only a word whose plausibility is under 0.6); `fixSound` (`media/fix.wav`, winmm). A fix by itself waits for the field's answer (`askField` → `field-worker.ts`, UI Automation `IsPassword` through `uia.ts`, 300 ms at most) and is called off in a password field (`callOff`, the ending key pressed as typed). `quietFullScreen`: `SHQueryUserNotificationState` refreshed by the clock; the hooks do nothing then. Learning (`learn`; `learning.ts LearnStore`, `learning.json`): `fixedByHand` (the fix key's conversion once typing goes on, `settleCycling`; or a word erased and typed again with the same keys in another layout within 10 s, `learnRetyped`) twice → `alwaysFix`; a word in no list, read as no word elsewhere, typed right (`noteCandidate`, counted when typing goes on past it) is tallied by a salted SHA-256 fingerprint and learned at `LEARN_AFTER` (3) into `myWords` (added to the lexicon at `MY_WORD_RANK`); nothing is learned before the field is known not to be a password. The 'layout' message carries Caps Lock and goes to the tray icon too (`trayLayout`: a keycap drawn by the tray panel's canvas, `drawLayoutCap`); `app` carries `elevated` (`winkbd.elevated`, token), named on the Keyboard page. The fix key over a selection selects the result again (`pressSelectBack`, then `selected` to the thread).
- **Translate in place** (`inPlaceKey`, on the Translate page): `useSelection('inPlace')` → `translateInPlace`: the translation pasted over the selection, no card, "…" in the badge (`keyboard.say`); the pair's model not downloaded or the window left meanwhile → the Translate card instead. **Paste into a web view** (VS Code's chat): `useSelection('translate')` keeps the field with the keyboard (`uia.focusedElement`), `pasteInto` waits for the window in front (`inFront`) and gives the field the keyboard back (`uia.focus`) before Ctrl+V. Translations are kept (`translationlog.ts`, `translations.json`, as the dictation log) when pasted, done in place or left in a closing card; Translate › Recent translations. From/To list the person's languages first (`CardState.mine`, optgroups). Settings: the pause key (registered even while paused) and the window key, the settings file (Export/Import/Reset), test versions (`betaUpdates`: the `beta` channel, every release carries beta.yml too, `generateUpdatesFilesForAllChannels`; a tag with a dash is published as a prerelease).

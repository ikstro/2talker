# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Altype ("Your language. Your shortcut."; called 2Talker until 0.3, tu-talk before that): a Windows tray app (Electron) that translates a picked text offline and reads the English aloud; it also translates any text both ways like DeepL, reads text from the screen, and switches and fixes keyboard layouts (in place of EveryLang). A sibling of the Language Tutor in `ikstro/cc-translator` (`E:\Cursor\Plugin\CC-translator`): the card's webview, the natural voice, the system voice and the word dictionary were copied from its `panel/` and adapted; the two repositories do not share code at build time.

## Commands

```
npm install
npm test                          # vitest
npx vitest run src/translate.test.ts
npm run typecheck
npm run build                     # esbuild: dist/main.js, preload.js, mt-worker.js, voice-worker.js, kbd-worker.js; media/card.js, app.js, tray.js; codicons into media/
npm start                         # build + electron .
npm run dist                      # electron-builder → release/2Talker-Setup-<version>.exe (NSIS, win-x64)
npm run icons                     # the "alt" keycap mark (build/icon.svg's shapes, drawn on a canvas under Electron) → build/icon.png (512), build/icon.ico (16–256), media/icon.png (128), media/tray.png + tray@2x.png (16 set pixel by pixel, 32)
npm run models                    # scripts/build-mt.mjs: src/mt-manifest.json + vendor/bergamot from Mozilla
node scripts/build-words.mjs      # media/layout/{en,ru,uk}.txt: the layout fixer's word lists (FrequencyWords)
cd engine; uv sync --extra speakers-gpu --group dev   # the speech engine for development, in engine/.venv
engine\.venv\Scripts\python.exe -m pytest engine\tests
```

One Altype at a time, always: `main.ts` takes the single-instance lock on Altype's own folder before anything else, so a second start (installed, `npm start` or a test run) hands its arguments to the first and quits. A test run (`ALTYPE_TEST_HOME=<folder>`: its own settings and speech engine folder, `ALTYPE_TEST_PORT`, 8797 by default, Windows' startup list left alone) therefore needs the installed Altype quit first.

Release: bump `version` in package.json, commit, tag `v<version>`, push the tag. `.github/workflows/release.yml` builds the installer on windows-latest and publishes the GitHub release with `latest.yml`; installed copies update from it (`src/update.ts`, electron-updater, checked at start and every 6 h, installed on quit). The installer is unsigned.

A shell started from VS Code or Claude Code may carry `ELECTRON_RUN_AS_NODE=1`; Electron then runs as plain Node and `electron.app` is undefined. Run with it unset (`env -u ELECTRON_RUN_AS_NODE …`).

## Architecture

Main process (`src/main.ts`): tray, the card window, the app window, flows. `%APPDATA%\2Talker\`: `settings.json` (`settings.ts`), `models\<code>\` (translator), `voice\` (Kokoro), `dict\`; `words.json` (`words.ts` `WordStore`: the notebook, one entry per dictionary form; `ankiTsv` for Anki's import); `adoptOldFolder` moves them over from `%APPDATA%\tu-talk` once. Closing the card (`hideCard`: Esc, ✕, a click elsewhere) also sends `stop` to the card, which plays the natural voice's audio itself.

- **Selected text**: `winclip.ts` registers the card window as a clipboard listener (user32 through koffi; `WM_CLIPBOARDUPDATE` via `hookWindowMessage`). `clipboard.ts` `DoubleCopy`: two changes 40–650 ms apart with Ctrl held = a request (`doubleCopy` setting); changes closer than 40 ms are one copy announced in several formats. Copies made inside the focused card are ignored. The selection shortcut (`selectKey`, none by default) waits until its keys are let go, presses Ctrl+C in the program in front (`pressCopy`, `keybd_event`) and takes the next clipboard change within 600 ms (`copyWanted`). `registerShortcuts()` registers it and `snipKey`; either may be empty.
- **Screenshot**: the snip shortcut (`snipKey`, default Ctrl+Alt+S) opens `ms-screenclip:` (Windows' snipping overlay); the next picture on the clipboard within two minutes is the snip (`clipboard.read()`, `image/png`; Electron 45's clipboard API is async). `ocr.ts` runs `Windows.Media.Ocr` through Windows PowerShell (`-EncodedCommand`, never `-ExecutionPolicy`), the person's language engine first (it reads Latin too), then English; `ocrtext.ts` joins lines into paragraphs by their boxes. Two purposes (`Purpose`), each from the selection or the screen: **listen** (the card above: `doubleCopy`, `selectKey`, `snipKey`) and **translate**, the translator (`translateKey` with `useSelection('translate')`, `textKey` with `snip('translate')` → `readScreenText`): the same card in kind `translate` or `text`, the text as it is (editable), Copy, From ⇄ To over the 32 languages, translated at once (`translateWindow`, `translateTextCard`). `translate.ts` `languageOf` guesses the source (a script of one language; letters of one language: қ… kk, і/ї/є/ґ uk, ђ… sr, ы/э/ё ru, پ… fa; else the language with most of its 200 common words in the text, `media/lang-words.json`; a short text: English by `media/layout/en.txt`), `targetFor` the target (the person's own, English from it), `translatePlain` translates through English when neither side is. No Translate button: an edit is translated again after a 700 ms pause (the last translation shown faded meanwhile), a language picked at once. Swap (framed, after the languages) swaps them and, a translation in, makes it the text (DeepL's way). Paste (blue; Enter on the window or in the field, Shift+Enter a new line; a translation still coming is pasted once in; only for a selection, `canPaste`): `pasteTranslation` brings back the window the text was selected in (`focusWindow`, `SetForegroundWindow` while the card is in front), hides the card and pastes over the selection through the clipboard. The selection keys (`useSelection`) and Paste put the clipboard back as it was (`saveClipboard`, `restoreClipboard`); Ctrl+C twice is the person's own copy.
- **Translation**: `translate.ts` `pairText` splits lines into sentences (`sentences.ts`) and decides each sentence's direction by script (`directionOf`): the person's script → into English (English shown, original behind the tap), Latin → into their language. Same-script natives (German…) are treated as English source for now. `splitText` + `translateLines`: when no sentence goes into English (`englishReady`), `main.ts` `translateInto` shows the English at once (`done` with the translation `translating`/`downloading`) and the card starts reading while the translation comes. `render.ts` writes two halves as plain paragraphs, one per line (no markdown: a picked text is not markdown; `sentences.ts` `unwrapLines` first joins lines broken mid-sentence: a line ending in a letter, digit, comma or hyphen followed by one starting in lower case without a list marker; a list item goes on so too): `englishHtml` (`span.s[data-i]`) and `translationHtml` (`span.t[data-i]`).
- **Translator** (`engine.ts`, interface `translator.ts`): Firefox Translations (Bergamot, WebAssembly, `vendor/bergamot`, shipped). Models per pair from Mozilla's attachment CDN, pinned with size and SHA-256 in `src/mt-manifest.json`, stored as `<sha256 head>-<name>`. `scripts/build-mt.mjs` picks, per direction, the newest complete version whose filter expression passes for Windows release (en→ru 2.0; the nightly 2.1 invents words). The engine runs in a worker thread (`mt-worker.ts`, loader via `vm.compileFunction`, Firefox's decoder config), ended after 5 idle minutes.
- **App window** (`media/app.html`, `src/webview/app.ts` with `ui.ts` (rows, keys), `speech.ts` (the engine's offers, models, the key) and `transcripts.ts` (Transcribe and Transcripts), `media/app.css`; the design is `design-lab/2026-10-27-altype/comps/01-chain/`, kept out of git): no Windows frame (`frame: false`); its header is the window's bar on every view (drag region: the "alt" keycap + "altype", pills Home · Words · Transcripts · About, Settings, then minimize and close drawn like the card's buttons, `{type: 'window'}`; close hides) over **Home**, always the first view: the chain line "ghbdtn vbh → привет мир → hello world" with Replay, a readiness line (`AppView.translator` for the person's pair, the natural voice, "runs on this computer"), and six action rows with the person's real keys (Listen, Translate, Screen, Dictate, Transcribe, Keyboard). The opening moment (5.7 s: the line is fixed, translated and read, each step's key lit, then it travels into the header and the keys drop into their rows) plays while `settings.introSeen` is false, which the page then sets; Replay plays it again. **A tapped row or pill grows into a full-window page** (its title and keys stay put as the page header, the other rows slide down and fade; Back and Esc fold it back; springs, no sheets): Listen, Translate, Screen (their keys, recorded from a press by `hotkey.ts` `HotkeyRecorder` — a tap waits `DOUBLE_MS` for a second one — clearable with ×, never two equal, "taken" from `keysOk`; card options; a text to try), Dictate (its three keys, the knowledge base folder and its notes subfolder, the dictation model; the engine's download offer while it is missing), Transcribe (a drop zone, also anywhere in the window, a file picker, language and speaker count, a microphone recording; the speakers part and the Hugging Face key with its live states and four steps; the Chrome extension's steps; the time an hour takes here, `minutesPerHour`), Transcripts (the library, searched by the words, and a transcript: in-place progress with stages, position and time left; speakers to rename and change; editable lines; the sound under it, a click on a time plays from there; export, copy, to the knowledge base, split by speaker or transcribe again, delete), Keyboard (switch and fix keys, the layouts in order, fixing as one types, programs left out, words kept, the badge, the rivals warning, the privacy line), Settings (language, voice and the natural voice download, speed, theme, start with Windows, the speech engine's parts, graphics card, service, folders and Remove, version and updates), Words (search, remove, Export for Anki, Copy), About (mark, tagline, author, links through `openLink` and the `LINKS` allowlist, credits). Fed by one `ToView {app, AppView}` snapshot, re-sent by `postApp()` on any change, and `appTab` (`AppTab`: home, the action pages, words, settings, about; the tray's "About Altype…" opens About); opened from the tray's panel, on the first run (Home), and by a second start without a command. Closing hides it.
- **Tray panel** (`media/tray.html`, `src/webview/tray.ts`, `media/tray.css`): Windows' tray menu cannot take Altype's look, so either click on the tray icon opens a frameless window of Altype's own by the icon (`createTrayPanel`, made at start and hidden between uses; `placeByTray` in `placement.ts`: on the side away from the taskbar, inside the work area; as tall as its content, `trayHeight`); it hides on blur, and a click on the icon that took its focus only closes it (`TRAY_REOPEN_MS`). Fed by `TrayView` (`refreshTray`): the brand and Open at the top (both open the window), the copied text → Listen (Ctrl+C twice) / Translate, a piece of the screen → Listen / Translate with their keys, Speech → New note / Transcripts once the engine is installed, the "Fix the layout as I type" switch, Quit as the last row; a command (`TrayCommand`) hides it and runs as the keys do. The voice, speed, language, theme and the rest live in the window only; "the selection" is not offered (from the tray it is gone).
- **Voice**: `synth.ts` + `voice-worker.ts` + `kokoro.ts` + `voicestore.ts` (natural voice, files from cc-translator's `voice-1` release), `speech.ts` (System.Speech), unchanged from the panel apart from paths and the `phonemes` message: the voice process's eSpeak gives a word's IPA for the word card (`lookup` → `ipa`), only while the natural voice is downloaded. `NaturalSpeaker` keeps the last 60 made sentences by text, voice and speed and mirrors the process's queue (`requests`): a new reading takes cached audio at once and waits for a sentence still being made for a stopped one instead of asking twice; the card asks for the sentence after each reading ahead (`speakNatural.ahead`), so ⏭ and the next paragraph start at once. `autoplay-policy=no-user-gesture-required` so the card can read before it is touched.

Card (`media/card.html`, `src/webview/card.ts`): the panel's `player.ts`, `hover.ts`, `dom.ts`, `voices.ts`; `preload.ts` exposes `window.tutorHost.post` and forwards `to-view` IPC as window messages. States: reading, translating, downloading, done (English + `TranslationState` of the lower half), empty, no-ocr, failed (`protocol.ts`). English on top (`.body`, read by Listen), translation under it (`.translation`, outside `.body` so the word card skips it); a click on an English word opens the word card (`hover.ts` `showAt`), a click on a sentence marks its pair (`.pair`); the language button hides the lower half; Esc closes. The remote under the English: ⏮ Listen ⏭ and the "One by one" chip (`oneAtATime`): Listen reads from a cursor (the sentence being read, via `PlayerEnv.entered`) to the end, or one sentence and waits; a finished full reading puts the cursor back at the top; Space and ← → work too. With two paragraphs or more, each gets a ▶ in a 26 px left margin (`addParagraphButtons`, shown on hover), reading that paragraph. The word card (`hover.ts`), opened by a click, takes clicks itself: say the word (`player.play` on a detached span), a star that saves it (`saveWord` with the sentence around it) or removes it. `rare.ts` draws a CSS Highlight `rare-word` (dotted underline) under words none of whose `baseForms` are in `media/common-en.txt` (3000 words, OpenSubtitles frequency, CC BY-SA; sent once as `common`); names mid-sentence are skipped; `rareWords` setting. The window follows the body's height (`height` message → `fitCard`), up to `cardHeight` or 70 % of the work area; it is resizable: a drag of an edge (`will-resize` … `resized`, never the card's own growing) saves `cardWidth` and/or `cardHeight`. Opens by the pointer (`placement.ts`), hides on blur unless pinned. The header draws the key that called the card (`CardView.via`, hotkey.ts notation, "Control+C*2" for Ctrl+C twice; main passes it from the key's handler, none from the tray) as lit keycaps, then the function's name (Listen, Listen · screen, Translate, Translate · screen).

Look: `media/theme.css` holds Altype's materials for every page — GitHub Light / GitHub Dark Dimmed colors as tokens (`--bg`, `--surface`, `--raised`, `--text`, `--strong`, `--muted`, pastel accents, `--accent`) chosen by `prefers-color-scheme` (which `nativeTheme.themeSource` sets from the `theme` setting: system, light, dark), Inter and JetBrains Mono bundled in `media/fonts` (OFL), radii, the type scale and the `.key` keycap (`.key.lit` for a key at work); the old `--vscode-*` names still point at the same colors. `main.ts` paints a window's background before its page (`cardColor`, `appColor`). The layout badge (`media/badge.css`) is an inverted keycap pill.

- **Keyboard helper** (off until a part is on: `switchKey`, `fixKey`, `autoFix`, `layoutBadge`): `keyboard.ts` `KeyboardHelper` runs `kbd-worker.ts`, a thread with Windows' low-level keyboard and mouse hooks (koffi `register`) and its own `GetMessageW` loop; the main process posts on a `MessageChannel` port and wakes it with `PostThreadMessageW` (`WM_APP`), the thread pulls with `receiveMessageOnPort`. All decisions are `typist.ts` `Typist` (unit-tested with a simulated text field, `typist.test.ts`): the keys typed since the last click as strokes (vk, Shift, Caps, layout id), never their letters; `hotkey.ts`: every key of the app, written like Electron's accelerators plus what only the hook can catch: a modifier tapped alone "LeftControl" or twice "LeftControl*2", a chord "Control+Shift", "Pause" alone, the mouse's side buttons "MouseBack", "Control+MouseForward". `isAccelerator` decides: the select, snip and text keys go to `globalShortcut` when Electron can hold them, to the keyboard thread otherwise (it reports `hotkey`, main runs the action); the layout keys are always the thread's. A tap acts at once; a double of the same key within `DOUBLE_MS` takes back the first tap's layout switch and acts. The switch key posts `WM_INPUTLANGCHANGEREQUEST` to the window in front with the next layout of `layouts` (all of Windows' when empty). At a word's end `layoutfix.ts` `chooseFix` (word lists `media/layout/*.txt`, trigram plausibility) may retype it: the hook swallows the ending key, `typeFix` runs after the hook answers (`WM_APP+1`): layout first, then Backspaces and the text (`winkbd.ts` `press`, `SendInput` marked `OWN_KEYS`), keys typed meanwhile pressed again. Backspace (or the fix key) right after takes it back and adds the word to `keepWords`. The fix key: the wrong tail since the last click (`wrongTail`), again round the cycle; after a selection (drag, double click, Shift+move, Ctrl+A) the main process converts it (`convertSelection`: copy, `convertText`, paste, clipboard restored, `ownClipboardUntil`). The badge: a 150 ms look at the layout in front, a click-through window (`media/badge.html`) by the system caret (`GetGUIThreadInfo`) or the pointer. `fixApps` leaves programs out; the settings warn when EveryLang or Punto Switcher runs (`findRivals`, `RIVALS`) and name, calmly, other programs that watch the keyboard (`KEYBOARD_APPS`: AutoHotkey, WhisperTyping…) and whether one presses keys by itself (`foreignKeys`: the thread reports the first injected key that is not Altype's, its main process's Ctrl+C/V marked `MAIN_KEYS`, or a mask key). Such keys never make or break a tap (a 2026-10-27 trace: a program pressed Right Ctrl+key 0.4 s after the owner's Shift+letter, which broke double taps before they were ignored).

- **Speech engine** (`engine/`, Python; came from the Altscribe app, 2026-10-27): a local HTTP service on 127.0.0.1:8765 for Dictate, Transcribe, the Chrome extension and other apps (`engine/app.py`'s docstring lists what they may rely on: `/dictate`, `/dictate/prepare`, `/transcripts`, `/recordings`, `/health`). faster-whisper large-v3-turbo for the words (float16 on an NVIDIA card; on the CPU int8, and `small` for dictation, as turbo takes ~6 s a 7 s phrase there), pyannote speaker-diarization-community-1 for the speakers (a Hugging Face token once, checked at once by `diarize.Setup`: whoami first, as a gated model answers a wrong key and a missing agreement alike), a library in SQLite with full-text search, one folder per transcript (`transcript.json` with every word's time, so speakers can be split later without recognizing again; `audio.ogg`). Installed **in parts** when a feature first needs one (`src/speechpack.ts`: pinned uv 0.13.0 downloaded and SHA-256 checked, `uv sync --frozen` with the parts as extras of `engine/pyproject.toml`: core ~330 MB, gpu (nvidia cuBLAS/cuDNN, offered when `nvidia-smi.exe` exists), speakers (torch CPU or CUDA; on the card its torch carries the CUDA libraries and replaces gpu) into `%LOCALAPPDATA%\Altype\speech` (env, python, uv, models), outside the app so updates keep it; progress is the download cache growing against `DOWNLOAD_MB`; a new `uv.lock` after an update syncs the same parts again). `src/speechservice.ts` runs `engine/app.py` under that Python (restarts with backoff, reuses an engine already on the port), `src/speechhost.ts` holds both and gives the window `SpeechView`; pages reach the engine through `window.tutorHost.call({call: 'speech', …})` (`host-call`, `HostCall`). The engine's settings are `%APPDATA%\Altype\speech.json` (`engine/settings.py`; Altscribe's `engine.json` and models are adopted once at a real start). **Dictate** (`src/dictation.ts`, badge `media/dictation.html` + `src/webview/dictation.ts`): `dictateKey` types the phrase where the cursor is (the badge never takes the focus; through the clipboard, put back as it was, `typeText`), `englishKey` the same after Altype's translator (`translatePlain`), `noteKey` records into the engine's library (`/recordings`, source note) and the engine writes a `.md` into the knowledge base's `Inbox`; Esc cancels; the keys are registered only once the engine is installed. The Chrome extension is `extension/` ("Altype: meeting recorder", Alt+Shift+M, as Alt+Shift+R is Chrome's Reading mode).

Packaging (`electron-builder.yml`): workers and `vendor/` are `asarUnpack`ed, and `node_modules/koffi` with them (the keyboard thread loads it from beside it); `main.ts` `unpacked()` maps their paths. The name is Altype (`productName`, installer `Altype-Setup-<version>.exe`, icon `build/icon.ico`); the `appId` and `setAppUserModelId` stay `com.ikstro.2talker`, so Altype installs over 2Talker, updates it, and its login item takes the same registry value; `oldfolder.ts` moves `%APPDATA%\2Talker` (and `tu-talk`) into `%APPDATA%\Altype` once. The GitHub repository is still `ikstro/2talker` (the publish target and the About links) until the owner says to rename it.

## Product rules (owner decisions, 2026-10-26)

- A separate app and repository (`ikstro/2talker`), not part of the VS Code tutor. Named 2Talker (was tu-talk); icon: a white letter A and a sound wave on a black tile (`build/icon.svg`).
- Offline translation, no Claude; quality below the tutor's is accepted; no A1–C2 levels. Engine: Firefox Translations (owner chose it over Opus-MT after a comparison).
- The result is a card by the pointer: the English on top, read aloud at once, the whole translation under it. An English text shows and reads before its translation is in. Closing the card (Esc too) stops the voice.
- A click on an English word shows its dictionary meanings, says it and saves it with a small star (the notebook, exported for Anki); a click on a sentence marks its other side. A dotted line under less common words, on by default.
- Interface in English only (the app is for English learners; no localization). English is the only learned language; the native language is any of the 31.
- Distribution: public GitHub repository and releases, unsigned installer, auto-update. macOS: not now.
- The author is shown: About tab and tray item, "Made by Yevhen Peshynskyi · Design automation engineer" with ikstro.com; the installer's publisher is the same name.
- The card: resizable by its edges, size kept; a remote with "one by one" for listening sentence by sentence; ▶ per paragraph in the margin, never on the words (a click on a word is its meanings). Speeds up to 1.5. Theme: as Windows, light or dark. Shortcuts: Ctrl+C twice (can be turned off), a selection shortcut, the snip shortcut, all changeable.
- Trigger for a selection: Ctrl+C twice; screenshot: Windows' snipping overlay behind a shortcut.

## Product rules (owner decisions, 2026-10-27): one app instead of EveryLang

- Text from the screen: its own shortcut (Ctrl+Alt+T); the snip's text in the card as it is, editable, Copy, translate into any language like DeepL (From → To); nothing read aloud. The snip with translation and voice stays as it was.
- Keyboard layout, in the public app, every part off by default: a switch key (default none; a tap of Ctrl like EveryLang, or any key), going through the chosen layouts in the chosen order; fixing as one types (Punto Switcher's way), EN/RU/UK word lists in v1, Backspace right after takes it back; a fix key (Pause like Punto) for everything typed in the wrong layout since the last click, or the selection; a layout badge by the cursor.
- All keys in Settings → Hotkeys, all changeable; an empty key is that part off. No separate Keyboard tab.

## Product rules (owner decisions, 2026-10-27): Altype

- The app is **Altype**, "Your language. Your shortcut."; the mark is the word "alt" on a keycap in a rounded frame; the wordmark "altype" in lower case; the brand of a system utility, laconic and technological. The author line stays.
- The look: GitHub Dark Dimmed's pastel colors in the dark theme (the owner's VS Code), GitHub Light in the light one; Inter and JetBrains Mono; neither Windows- nor Mac-looking; the feel of ikstro.com.
- No Windows look: the window has no Windows frame (its own bar, minimize and close like the card's), and the tray opens Altype's own panel instead of Windows' menu (the owner chose it over a shorter Windows menu).
- The window: Home first, always; the chain line (one text through fix → translate → listen) as its header, played once as the opening moment; every action a row with its keys; **a tapped row grows into its page** (no bottom sheets — the owner rejected them); keys live on their action's page, not in Settings. Every card shows the key that called it.

## Product rules (owner decisions, 2026-10-27): Listen and Translate

- Two functions, each for the selection and for a piece of the screen. **Listen**: the card as before (English read aloud, its translation under it, word meanings): Ctrl+C twice, the listen key, Ctrl+Alt+S. **Translate**: a window with the text and its translation, like DeepL: the translate key (none by default; the owner uses Shift twice), Ctrl+Alt+T for the screen. Translated at once, never read aloud.
- The direction is a rule, never remembered: a text in the person's language → English; any other → the person's language. The language is detected (32 languages); From and To can be changed in the window, for that window only; Swap turns it round (the translation becomes the text).
- No Translate button. Paste (the main, blue button; Enter, as a chat sends) puts the translation over the selected text, for a selection only; Swap is a framed button after the languages. 2Talker leaves the clipboard as it was.
- A list item broken mid-sentence goes on in the next line (lower case, no marker of its own): joined, in both cards.
- Any key may be a double tap of a modifier (Translate the selection on Ctrl twice), a modifier alone, modifiers together, Pause or Caps Lock alone, or a mouse side button. A tap that switches the layout acts at once; the double of the same key takes the switch back.

## Product rules (owner decisions, 2026-10-27): speech — Dictate, Transcribe, meetings

- One app: Altscribe (a separate transcriber) is merged into Altype and retired; its engine and Chrome extension live here. Its transcripts, Hugging Face key and knowledge base folder are taken over.
- Interface in English, as everywhere in Altype; transcripts and notes are in whatever language was spoken.
- Available to everyone, off until wanted: a feature that needs the speech engine offers its download (with the size) and shows the install and the model download as they go. One speech service is shared by every feature and by other apps (dictation, recognition, the extension, later the VS Code tutor).
- Home rows: **Dictate** (three keys: type here, type in English, a note into the knowledge base) and **Transcribe** (files, the microphone, Meet). The library is **Transcripts**, a pill in the header beside Words.
- Text after a meeting, not live. Speakers split per person; in a meeting the microphone is "Me" by its own track and the tab's voices are split by the model.
- Source files are never copied or kept; a compressed copy of the sound (~11 MB an hour) is kept to hear a line again. Every wait shows where it stands (stages, position in the recording, time left), and a saved key shows at once whether it works.
- New users' transcripts: `Documents\Altype\Transcripts`.
